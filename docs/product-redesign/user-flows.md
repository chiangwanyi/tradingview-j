# 用户流程与导航

> 本文件描述"用户想做什么"以及"界面上从哪到哪"。不描述数据结构，也不描述 Pinia Store。
> 标记沿用：`[事实]` / `[建议]` / `[待确认]`。

---

## 1. 用户进入系统时的三种处境

| 处境 | 用户心里的问题 | 界面第一屏应该给的答案 |
|---|---|---|
| 有进行中的考核，今天还没练 | 我该练哪个账户？还剩多少空间？ | 账户状态 + 剩余空间 + 「继续训练」 |
| 有进行中的考核，刚平完一单 | 我这一单把风险用到哪了？ | 当日盈亏变化 + 日亏/回撤剩余 + 结论句 |
| 没有考核账户 | 这东西怎么开始？ | 「新建考核账户（演示）」+ 一句规则说明 + 自由研究入口 |

第四种处境（已通过 / 已失败）见场景 E。

## 2. 导航结构

`[建议]` 一条常驻顶栏（48px），三项一级导航 + 右侧账户切换 + 右下角模式徽章：

```
┌────────────────────────────────────────────────────────────────────────┐
│ 考核训练  │ 概览   训练   记录                 [账户 ▾]  ● 已连接  ?  │ 48px
├────────────────────────────────────────────────────────────────────────┤
│                        页面内容                                        │
└────────────────────────────────────────────────────────────────────────┘
```

| 导航项 | 路由 | 权重 |
|---|---|---|
| 概览 | `/` | 默认首页，任何"回首页"都到这里 |
| 训练 | `/train` | 一对一入口：当前选中账户的训练工作台；未选账户时进入选择态 |
| 记录 | `/records` | 含月历 / 当天 / 统计三个 Tab（现状不变） |

- **默认首页 = 概览**。理由：产品目标是考核，而考核的答案在概览；把画布留作首页等于默认"用户已经知道要练什么"。
- **账户切换器**在顶栏右侧，不在页面里。理由：切换账户会改变**三个页面**的内容，属于全局上下文，
  放在概览页里会导致"在记录页看不见自己在哪个账户上"。
- **规则与设置是抽屉**，从账户卡右上角「规则」和切换器底部「管理账户」进入，不占导航。

`[建议]` 不设面包屑。层级只有一层，加了是装饰。

## 3. 场景 A：查看考核进度（MVP 必做）

```
启动 → 概览页
        ├─ 第一屏读到一条结论句（"目标完成 62%，今天还能亏 $1,150，回撤还剩 $2,400"）
        ├─ 看到账户身份：名称 / 规模 / 类型 / 状态徽章 / 第 N 个交易日
        ├─ 看到两个剩余空间：今日（横条 + 金额）、总回撤（横条 + 金额）
        └─ 看到最近 5 笔 + 今日小结
```

关键步骤与守卫：

| 步骤 | 交互 | 异常 |
|---|---|---|
| 扫一眼判断"急不急" | 结论句 + 两个横条的**填充比例** | 若数据不足（无权益/无交易日）→ 结论句降级为"还没开始"，横条置灰并显示"待开始" |
| 想看某个数字怎么来的 | 悬停/点数字 → 一行口径说明（"今日盈亏 = 当日已平 + 当前浮盈，按 06:00 起算"） | 口径 `[待确认]` 时，说明写"演示口径"而非编一个公式 |
| 想看别的账户 | 顶栏账户切换器（或概览页顶部账户 chips） | 只有一个账户时不显示 chips，避免"永远在选一个" |
| 想开始练 | 右上「继续训练」/ 主按钮 | 账户已通过/已失败 → 按钮变「查看结论」，不可进入训练（`[待确认]` Q8） |

## 4. 场景 B：开始或继续训练（MVP 必做）

```
概览 → [继续训练] → 训练工作台 /train
                     ├─ 顶部账户风险条（32px）：权益 · 今日盈亏 · 日亏剩余 · 回撤剩余
                     ├─ 若不是同一标的/锚点 → 先出「选择起点」面板（最新 / 开盘 / 指定时间）
                     └─ 进入后：逐根推进 → 挂单 → 成交 → 平仓 → 风险条数字实时变化
```

- **起点怎么定**：沿用现有三个入口（最新 / 随机开盘 / 指定时间）。`[建议]` 在考核模式下，
  默认推荐"**继续上次的实例**"（如果存在）而不是"随机开盘"——考核是一个连续过程，
  每次随机跳日期会让"交易日计数"和"跨日持仓"变得没有意义。
- **训练中的模式提示**：工作台顶栏常驻一枚徽章 `考核模式 · 账户 A`；自由研究时是 `自由研究 · 不计入考核`。
  按 P1，这枚徽章**不能被折叠**。
- **风险越线**：当日亏损用到 80% 时，风险条变强调色 + 文案"今日还剩 $200"；
  触线时**不自动平仓**（`[待确认]` Q4：是警号还是硬停），只把状态卡置为"当日失效"。
  自动平仓是交易行为，不能由前端决定。
- 离开工作台（回概览/记录）**不结束考核**，也不结束实例——沿用 F4 的"实例是服务端概念"。

## 5. 场景 C：观察交易风险（MVP 必做）

这不是一个独立页面，而是贯穿概览与工作台的一条**语义规则**。用户的心智路径：

```
"我今天亏了 $430"          → 当日盈亏（一条，不是三处不一样的数字）
"这 $430 里有多少已经落袋"  → 已实现盈亏（余额变化）
"还剩多少浮盈/浮亏没结算"    → 未实现盈亏（权益 − 余额）
"今天还能再亏多少"          → 日亏限制 − 当日亏损（只看亏损侧）
"万一连亏几天会不会直接死"   → 总回撤限制 − 当前回撤
```

`[建议]` 界面上把这五个数分成两层，**不要并列**：

- **第一层（大字号，一屏内）**：权益、距目标还差、日亏剩余、回撤剩余。
- **第二层（小字号或悬停展开）**：余额、已实现、未实现、峰值权益、当日交易笔数。

理由：余额和权益在"无浮盈"时恒等，并列展示会让用户以为其中一个是错的。

## 6. 场景 D：回顾历史表现（MVP 必做，能力已有）

```
顶栏「记录」→ /records（月历，带账户筛选）
               ├─ 点某一天 → /records/day/:date（八 KPI + 六图 + 逐笔）
               │              └─ 点某一行 → 回画布逐格演这一笔（现有能力）
               └─ 切「统计」Tab → 全部记录汇总 + 标签筛选（现有能力）
```

本次只加一件事：**筛选条多一个「账户」维度**，并且明确显示"这些记录是否计入了考核"。

| 情形 | 界面表现 |
|---|---|
| 记录属于当前账户 | 列表行带 `计入考核` 小标签 |
| 记录来自自由研究 | 行带 `自由研究` 灰标签，且**不计入**概览的进度 |
| 一条记录都不属于任何账户（历史数据） | 归为 `未归类`，默认可见，不迁移、不删除（`[待确认]` Q10） |

`[建议]` 从某笔交易进入详情的路径保持现状（行内点击 → 抽屉/当天页）。理由：现在的行点击已经能回放，
新建一个"交易详情页"会把"这一天"和"这一笔"拆成两条互不相关的路线。

## 7. 场景 E：查看考核结果（MVP：状态卡 + 结论抽屉）

```
触发条件（通过 / 失败）
  → 概览页该账户的状态徽章变「已通过」/「已失败」
  → 账户卡置顶一条结论条：原因 + 关键数字 + 时间
  → 点「查看结论」打开抽屉：
       结局（通过/失败）· 触发规则（哪一条、什么时候、差多少）
       · 关键节点（起始余额、峰值权益、最大回撤、最后一个交易日）
       · 相关交易（最近 N 笔，可点开回放）
  → 训练按钮禁用，工作台进入只读（可以看盘、不能下单）
```

- **不做独立结果页**：结果是一次性的信息，不是需要反复回来的目的地。
- **只读不等于不能进**：`[建议]` 已结束的账户仍可进工作台看盘（复盘价值），只是下单按钮禁用并提示原因。
- `[待确认]` Q8/Q9：通过后能否继续交易、失败后能否重置。演示中按"只读 + 可归档"表现。

## 8. 页面跳转总图

```
                ┌──────────────── 顶栏（常驻） ────────────────┐
                │  概览  │  训练  │  记录        [账户 ▾]      │
                └───┬───────┬────────┬────────────────────────┘
                    │       │        │
   自由研究模式 ────┤       │        │
   （独立入口，     ▼       ▼        ▼
    不选账户）    /        /train   /records
                 概览      工作台    月历 ──点击某天──▶ /records/day/:date
                  │  ▲       │                        │
      [继续训练]──┘  └───────┘  离开不结束考核          │
                  │                                    │
                  └───── 点某笔「回放」 ────────────────┘
                            （回到工作台，进入回放态）
```

`[建议]` 模式切换（自由研究 ↔ 考核）放在**顶栏账户切换器的第一项**：
`自由研究（不计入考核）` / `考核账户 A` / `考核账户 B` / `管理账户`。
理由：模式和账户是同一件事的两面，分成两个控件会让人忘记自己现在在哪一档。

切换时的守卫（P1 的核心）：

- 切换账户 = 离开当前实例的**观看**状态，不删除实例；
- 若当前有未平仓位，切换时弹确认："账户 A 还有 1 手持仓，切走后这一单仍记在 A"；
- 自由研究下的记录**永远不进入**任何账户的统计，界面上不许出现"要不要算进去"的选项
  （给了这个开关，就一定会有人算错）。

## 9. MVP 与后续迭代的分界

| 流程 | MVP | 后续 |
|---|---|---|
| A 概览 | 单账户主卡 + 多账户切换 | 多账户并排对比、排行榜 |
| B 训练 | 风险条 + 账户徽章 + 从概览进入 | 训练计划/课程、多显示器布局 |
| C 风险 | 两个剩余空间 + 只读口径说明 | 盘中实时告警、每笔风险预算（R 倍数） |
| D 记录 | 账户筛选 + 计入标记 | 标签钻取、按账户对比、导出 |
| E 结果 | 状态卡 + 结论抽屉 | 结论文档导出、证书/分享 |
| 规则 | 只读抽屉 + 演示参数 | 规则模板（按 PF 公司）、规则变更历史 |
